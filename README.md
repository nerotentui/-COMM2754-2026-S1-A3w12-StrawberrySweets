# -COMM2754-2026-S1-A3w12-StrawberrySweets
- Capable of Healing Program Version 1.0 22/5/2026
- Usage Notes: This program is a website contains generative P5 artworks. In "Destruction" click to spawn stars and click to target trees. Once the trees are all gone the stars die. In "Harmony" the star tracks the user cursor. click to plant trees, hover over orbs to collect oxygen.
- Unzip COMM2574-2026-S1-A3w12-StrawberrySweets-Compilation.zip. Users should start a web server in the root directory and then access the index.html file in their browser to see and hear the results. No dependencies or plug-in installation is required.
